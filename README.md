# программа бинарного дерева поиска на C++

эта программа (файлы «secondtree.cpp», «tree.cpp», «html.cpp») нужна для работы с бинарным деревом поиска. в ней мы можем добавлять, удалять и искать элементы этого дерева. код написан на языке С++, но также был использован язык гипертекстовой разметки HTML для отображения результатов программы.
после операций добавления или удаления программа сохраняет текущее состояние дерева в файл «output.html», где его можно посмотреть в виде схемы, для визуализации которой используется Mermaid.js.
после завершения программы нужно будет открыть файл «output.html» в браузере, чтобы увидеть результат работы данной программы.

структура проекта:
- в папке «include» лежат заголовочные файлы: «tree.h» (классы Node и Tree) и «html.h» (функции f1 и f3);
- в папке «src» лежат реализации: «tree.cpp» и «html.cpp»;
- «secondtree.cpp» содержит меню программы;
- «CMakeLists.txt» нужен для сборки через CMake.


сборка через CMake:
cmake -S . -B build
cmake --build build


запуск: «./app» или «./build/search_tree» (на Windows «.\app.exe» или «.\build\search_tree.exe»).
